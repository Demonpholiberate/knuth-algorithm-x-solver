## 🛠 Feature Breakdown

### Feature 1 — Exact Cover
Model problems as rows and columns of 0s and 1s.

### Feature 2 — Dancing Links
Use circular doubly-linked lists for O(1) node removal.

### Feature 3 — Algorithm X
Backtracking search that always picks the column with fewest 1s.

### Feature 4 — Sudoku Solver
Turn a 9x9 grid into a 729-row exact cover matrix.

### Feature 5 — N-Queens
Solve the classic N-Queens problem in milliseconds.

### Feature 6 — Optimization
Reduce memory footprint and speed up the search.
